# فونت‌ها

فایل‌های فونت باینری هستند و از طریق ابزار خودکار ترجمه قابل کامیت نبودند.
این فایل‌ها را از ریپوی `themahdipixl-dev/Assets` (پوشه `assets/`) دانلود کنید و **با همین نام‌ها** اینجا بگذارید:

- `Vazir-Thin-FD-WOL.ttf`
- `Vazir-Light-FD-WOL.ttf`
- `Vazir-FD-WOL.ttf`  (فونت پیش‌فرض UI)
- `Vazir-Medium-FD-WOL.ttf`
- `Vazir-Bold-FD-WOL.ttf`
- `Lalezar-Regular.ttf`  (فونت عنوان)

بعد از کپی، پروژه را یک بار در ادیتور Godot باز کنید تا import شوند.
تا وقتی فونت‌ها نباشند، Godot از فونت پیش‌فرض/سیستم استفاده می‌کند (متن فارسی ممکن است ظاهر متفاوتی داشته باشد).
