# نانوایی سنگک (Noonvaei)

بازی موبایل idle/tycoon ایرانی: نانوایی سنگک خودت رو می‌چرخونی، بخش‌های مختلفش رو ارتقا می‌دی و درآمدت رو بالا می‌بری.

- موتور: **Godot 4.7** (GDScript)
- پلتفرم: اندروید، حالت عمودی (portrait)
- زبان: فارسی (راست‌به‌چپ)

## اجرا
1. Godot 4.7 یا جدیدتر رو نصب کن.
2. پوشهٔ پروژه رو توی ادیتور باز کن و F5 بزن.
3. فونت‌ها و تصاویر لازم در `assets/` هستند (فهرستشون در `assets/README.md`).

## خروجی اندروید
پریست آماده در `export_presets.cfg` است. تمپلیت‌های Export و Android SDK/JDK رو نصب کن و از *Project > Export* خروجی بگیر.

## ساختار
- `scripts/game/` منطق بازی (اقتصاد، ذخیره، وضعیت)
- `scripts/world/` دنیای بازی (نقشه، نانوایی، پیاده‌رو، شاطر، ماشین‌ها)
- `scripts/ui/` رابط کاربری (HUD، نوار پایین، پنل ارتقا)
- `scripts/config/` اعداد بالانس و متن‌ها

راهنمای فنی برای توسعه در `CLAUDE.md` است.
